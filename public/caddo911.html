Caddo 911 active calls in Shreveport and Caddo Parish

The Caddo Parish 911 Communications District publishes a list of active events. Louisiana911 checks that list about once a minute and shows each call on the map and in the list. Past calls stay in History, so you can look back through earlier days like a call log. This site started as Caddo911 and still covers the same feed.

  • Source: Caddo Parish 911 active events page
  • Timing: Live. Calls leave the list when the source removes them and stay available in History.
  • Area: Shreveport and the rest of Caddo Parish

Police, fire, sheriff, and EMS calls

  • SPD: Shreveport Police Department
  • SFD: Shreveport Fire Department
  • CSO: Caddo Parish Sheriff's Office
  • CFD: Caddo Parish fire districts

Each call keeps the description, time, street, cross streets, area code (for example SHV), agency, and unit count as published.

Map locations

Addresses and intersections are matched to a map point and checked against the Caddo Parish boundary. If the feed gives a street between two cross streets, the marker goes on that stretch of street. If a location can't be matched with confidence, the call stays in the list without a marker.

Limits

The source is a list of active calls, not case records. A listed call doesn't mean a crime happened, and a call leaving the list doesn't tell you how it ended. Louisiana911 is independent and not affiliated with Caddo Parish 911 or any responding agency.
